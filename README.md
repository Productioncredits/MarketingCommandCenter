# Workspace Starter

This project is a minimal static web app scaffold for VS Code.

## Open the app

- Press F5 in VS Code and choose the Chrome launch config
- Or run the task: `Open app in browser`

## Files

- `index.html` — app entry point
- `styles.css` — styling
- `app.js` — page behavior
- `.vscode/launch.json` — debugging config
- `.vscode/tasks.json` — browser task

## Notes

This setup is intentionally lightweight and does not require a framework or build step.
